Rollercoaster Animation

For my creative coding class, I made an animated rollercoaster in the web browser. To model the rollercoaster, I used Rhino and Grasshopper. I structured my files so that I could simply draw a line in Rhino, and then Grasshopper would convert it into a rollercoaster track. To render the rollercoaster in the web browser, I used Three.js. Through Grasshopper, I was able to export a series of x, y, and z coordinates that lie on the rollercoaster track. My Three.js code then reads these coordinates to move a camera along the track, creating an on-ride point-of-view. I also added a 2D logo to my animation using p5.js.
From this project, I learned more about Three.js and especially its camera system. I also learned how to get different software programs and JavaScript libraries to work together to make a cohesive experience. View the rollercoaster here!
