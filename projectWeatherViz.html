Weather Visualization

This is a visualization of weather data for the Denver metro area. The sky color is mapped to the temperature of each day, and rain and snow are shown for days that had those weather conditions. I gathered the data from publicly available NOAA records collected at the Denver Airport.
This project was made using Three.js, p5.js, HTML, and JavaScript. This was also my first time using Blender.
